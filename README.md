# 写作台

面向 Windows 11 的本地写作软件，适用于长篇写作场景（小说、剧本等）。全部数据保存在本机，无需登录。

## 功能总览

- **文章**：顶层创作单元，可挂载章节、人物关系、时间轴三类子项目，支持大纲
- **章节**：富文本文本窗口，回车缩进、统一字号、选区加粗 / 斜体、独立字数统计，支持 F11 全屏
- **人物关系**：人物、阵营、小传，导出 .svg / .csv
- **时间轴**：乱序录入、拖拽排序、关联章节与人物，导出 .svg / .csv
- **导出**：章节 .md / .rtf / .png；全书合并 .rtf / .pdf
- **数据**：本地备份 / 合并导入、批量删除 / 批量导出、码字统计

## 使用说明

### 一、我的文章

- 主页输入标题，回车或点「新建文章」创建，点击卡片进入文章工作区。
- 文章卡片提供「打开」「删除」操作；删除会连同其全部子项目一并移除（有确认提示）。

### 二、我的灵感

- 主页输入标题，回车或点「+ 新建灵感」创建，标题留空则默认「未命名灵感」，点击卡片展开编辑。
- 灵感为独立富文本，记录想法、点子、片段与素材。

### 三、人物关系

- 列头「+ 新建」直接创建关系图；添加人物与阵营（一人可加入多个阵营）、连线建立关系。
- 拖放人物卡片到阵营标签入营 / 移出。
- 选中人物弹出信息浮窗，可自由拖动、可关闭。
- 画布可拖动、平移、缩放。

### 四、时间轴

- 列头「+ 新建」直接新建文段，填写时间（可空）、事件（必填）与描述。
- 按住文段手柄拖拽排序；文段可关联章节与人物（关联面板支持搜索）。
- 删除章节、人物关系或人物后，指向它们的时间轴关联自动清除。

### 五、章节

- 列头「+ 新建」添加章节并自由书写。
- 侧栏统一设置字号与首行缩进，选中文字可加粗、斜体。
- 编辑状态（光标在编辑器内）按 F11 全屏化该文本窗口，再次按 F11 或 Esc 退出。
- 列头「顺序」切换正序 / 逆序。
- 列头「导出」选全部或指定文本窗口，格式 .md / .rtf / .png。

### 六、批量删除

- 主页右栏「批量删除」点「进入批量模式」，勾选多个文章或灵感（可全选 / 清空），点「删除所选」一次性删除。

### 七、批量导出

- 主页右栏「批量导出」点「进入批量模式」，勾选多个文章或灵感，点「导出所选 (.rtf)」并选择一次文件夹，逐个导出为独立 .rtf 文件（重名自动加序号）。

### 八、本地备份

- 主页右栏「本地备份」：将全部数据快照保存为 JSON 文件（`xiezuotai-backup-日期-时间.json`）到自选文件夹。
- 菜单「文件 → 保存」（Ctrl+S）：一键备份到本机数据目录的 `backups` 文件夹，无需选择路径。

### 九、本地导入

- 主页右栏「本地导入」或菜单「文件 → 导入」：选择备份 .json 文件，确认后**仅修正备份中的文章与灵感**：
  - 同 id 的文章 / 灵感以备份版本覆盖（标题、大纲、格式及章节等子项目按 id 覆盖 / 补入）；
  - 备份独有的文章 / 灵感 / 章节补入；
  - **导出后新增的文章、灵感与章节保留不变**，统计与码字记录沿用当前数据。

### 十、数据统计

- 主页右栏「数据统计」：展示今日 / 年度 / 累计的码字字数与码字时长，并以月历标注每日字数。

### 文章工作区顶部

- 「大纲」：展开 / 收起文章大纲（母任务内容）。
- 「导入」：读取人物关系或时间轴表格文件（.rtf / .csv / .svc，按表头自动识别类型）。
- 「导出」：弹出导出面板，勾选「章节全部内容（合并为一个文档）」「人物关系」「时间轴」并各自选择格式（章节：.rtf / .pdf，关系与时间轴：.svg / .csv）。

## 数据保存位置

- 桌面版数据保存在本机用户数据目录（`%APPDATA%/writing-studio`），更名前版本的数据目录自动沿用与迁移。
- 浏览器预览环境数据保存在浏览器 localStorage。

## 开发与构建

```bash
# 安装依赖
npm install

# 浏览器开发预览（Vite，端口 5173）
npm run dev

# 桌面开发模式（Electron + Vite）
npm run electron:dev

# 渲染层生产构建
npm run build

# 打包 Windows 安装包（NSIS，输出 release/）
npm run electron:build
```
